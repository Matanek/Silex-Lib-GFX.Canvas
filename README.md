# GFX.Canvas

`GFX.Canvas` records portable 2D drawing intentions and turns them into vector
geometry or RGBA images without imposing a window or renderer.

```text
silex install GFX.Canvas
```

## Documentation

- [French documentation](Docs/FR/README.md)
- [English documentation](Docs/EN/README.md)

This release requires Silex 0.48.0 or newer, including protocol default bodies
and native C callback support used by the desktop accessibility adapters.
